Review the underlying record(s) and describe the **user impact** of each option, so the owner can make a decision.
Go through each records one by one and see if we can resolve the topics. Skipping a topic by the user is allowed. 
Ask after each record. I don't want a '1/n' question box.

For each:
- Make sure the topics are still relevant, all from code, SoR, and catalog perspective. 
- Update every record and its relatives after the decision is done.
- Perform a requirement/ac/user_need/architecture_description/interface_spec/design_decision/code consistency check.
- Move to an executable iteration. Try not to create new iterations
- Unblocked issues shall be concluded using conclude skill to an approved cr.
